# SALONERIDE# SaloneRide: Ride Booking and Payment System

SaloneRide is a prototype ride-hailing and payment software designed around the needs of passengers in Sierra Leone. It addresses common challenges in informal transport systems by providing upfront fare estimates, booking confirmation, and support for local payment methods including **Cash**, **Orange Money**, and **Afrimoney**.

This repository contains the **Dart console-based prototype** developed as part of academic coursework (Software Engineering).

---

## Features
* **Passenger Profile Creation:** Register a passenger name and phone number.
* **Ride Request Workflow:** Input custom pickup locations and destinations.
* **Transparent Fare Estimation:** View estimated trip fares in New Leones (NLE) prior to booking.
* **Flexible Payment Options:** Choose between Cash, Orange Money, and Afrimoney (with a simulated PIN verification prompt).
* **Simulated Dispatch & Tracking:** Automated driver assignment status updates (*Pending* ➔ *Accepted*) and trip completion flows.
